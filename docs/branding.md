# Branding & Assets

This folder contains the official Relicbound branding assets and a short style guide.

- Logo: `assets/branding/logo.svg` (vector). Use this for headers and converted PNGs for server icons.
- Colors:
  - Primary: #6A1B9A (deep purple)
  - Accent: #FFB74D (warm amber)
  - Background: #0F1720 (dark slate)

Usage:
- Include `logo.svg` inside the resource-pack at `resource-pack/assets/relicbound/textures/branding/logo.svg` if you want an in-pack icon.
- For server listing banners, export `logo.svg` to PNG at 128x128 and 512x128.

If you want a custom, hand-drawn logo, replace `assets/branding/logo.svg` and the copy in the resource-pack.
