Witch Plugin — Documentation
==========================

Welcome to the Witch Plugin docs. This repository contains the plugin source, a generated resource-pack, and documentation to help server admins and contributors.

Docs included:

- Quickstart: setup and install the plugin and resource-pack.
- Architecture: high-level overview of core modules and patterns.
- Spell Compendium: auto-generated list of spells from resource-pack/manifest.json.
- Developer guide: how to add spells and regenerate the resource-pack.
- Branding: logo and style guide assets.

If you're a contributor, start with `docs/developer.md`.
